# 提交意图：建议合并

贡献人：@lykketutu。

味觉档案是一份可拆卸的吃喝体验档案：聊天记录一笔，页面提供月历、产品卡、配置对比、复购画像、评分设置、草稿整理和月度报告。本次提交完整 1.1.0 模块，按当前稳定 memoryId 合同接入 SDK v2 MCP，不修改 Core。

## 接入边界

- manifest 自动发现页面；使用 /developer-kit/runtime.js 与 stone-module-page，身份来自宿主 memoryId。
- Provider 注册 list/stats/add/update/digest 五个工具。只读操作复用 reader，写入经 context.runCommand → 正式模块 CLI；会话 Binding 注入当前记忆体，工具参数不能指定其他记忆体。
- 配置、尝试记录、报告和草稿只存模块私有目录；不写正式记忆数据库、full 或活动线程，不调用模型，不保存凭证。
- MCP 默认关闭，使用正式 CLI 按记忆体开通，再重连客户端；安装不会自动启用权限或改写用户规则。
- 新自动记录模板优先 MCP，CLI 后备改用 --memory；删除、清空和合并须明确确认。
- 移除模块代码不会删除模块数据或规则；回退旧包前停用本模块 MCP。1.0.0 数据格式不变，无迁移。

## 验证范围

模块单元与真实 MCP 子进程测试覆盖五个工具、CLI 写入、启停、会话绑定、记忆体隔离、无文件读取、非法参数及确认门槛。使用临时 HOME 和合成数据，不调用真实模型。

浏览器在 1366×900 和 390×844 尺寸操作过页面载入、视图切换、空月份、记录弹窗打开/长文本/取消、返回与刷新、新规则点亮及暂停；手机尺寸不代表实体手机验收。Claude/Codex 的原生客户端重连及真实模型自动记录未作为本次验收依据。

具体测试命令与 MCP 启停方式见 README.md；CI 结果以 PR 上的实际运行状态为准。
